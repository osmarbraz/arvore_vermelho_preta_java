# Implementação recursiva de Árvore Vermelho e Preta Encadeada em Java
Operações implementadas recursivamente com árvore vermelho e preta encadeada:<br>
- Inserir<br>
- Excluir<br>
- Alterar<br>
- Caminhar Pré<br>
- Caminhar Central(In)<br>
- Caminhar Pós <br>
- Caminhar Em nível<br>
- Contar nós da árvore<br>
- Localizar nó na árvore<br>
- Mostrar folhas da árvore<br>
- Altura da árvore<br>
- Valor máximo na árvore<br>
- Valor mínimo na árvore<br>
- Apagar árvore<br>

* Baseado no livro de Thomas H. Cormen 3 ed. Página 262.
